# 生产环境部署指南

本文档说明如何将 **AI多平台视频下载分析平台** 部署到生产服务器（以阿里云 ECS 为例）。

---

## 一、服务器配置建议

### 最低配置
- **CPU**: 2核
- **内存**: 4GB（建议 8GB，Whisper 语音识别较耗内存）
- **磁盘**: 40GB
- **操作系统**: Ubuntu 22.04 LTS

### 推荐配置
- **CPU**: 4核
- **内存**: 8GB
- **磁盘**: 100GB
- **带宽**: 5Mbps+

---

## 二、前置准备

### 1. 域名与 DNS

- 注册域名并备案（国内服务器必须）
- 配置 A 记录指向服务器公网 IP

### 2. 安全组配置

开放以下端口：
- `22` - SSH（仅限特定 IP）
- `80` - HTTP
- `443` - HTTPS

### 3. 必需的 API Key

- **DeepSeek API Key**（必需）：[获取地址](https://platform.deepseek.com/api_keys)
- **Stripe 密钥**（可选，VIP 支付功能）：[获取地址](https://dashboard.stripe.com/apikeys)

## 四、部署后端

### 1. 克隆代码

```bash
cd /home/deployer
git clone https://github.com/xixi-xjl/AI-Video.git
cd your-repo
```

### 2. 配置 Python 环境

```bash
cd backend
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 3. 配置环境变量

```bash
cd /home/deployer/your-repo
cp .env.example .env
nano .env
```

**生产环境 `.env` 配置示例：**

```env
# AI 大模型
DEEPSEEK_API_KEY=sk-your-production-key

# JWT 密钥（务必使用强随机字符串）
JWT_SECRET=your-super-secure-random-string-change-this-in-production

# Stripe 支付（生产环境用 live 密钥）
STRIPE_SECRET_KEY=sk_live_your_stripe_live_key
STRIPE_WEBHOOK_SECRET=whsec_your_production_webhook_secret
STRIPE_PRICE_ID_MONTHLY=price_your_production_price_id

# 前端 URL
FRONTEND_URL=https://yourdomain.com

# Whisper 配置
ENABLE_WHISPER=true
WHISPER_MODEL=base
WHISPER_DEVICE=cpu
WHISPER_COMPUTE_TYPE=int8
MAX_ASR_SECONDS=1800

# 管理员账号
ADMIN_EMAIL=admin@yourdomain.com
ADMIN_PASSWORD=your-secure-admin-password
```

### 4. 配置 systemd 服务

创建服务文件：

```bash
sudo nano /etc/systemd/system/video-downloader.service
```

写入以下内容（**注意替换路径**）：

```ini
[Unit]
Description=AI Video Downloader Backend
After=network.target

[Service]
Type=simple
User=deployer
WorkingDirectory=/home/deployer/your-repo/backend
Environment="PATH=/home/deployer/your-repo/backend/.venv/bin"
ExecStart=/home/deployer/your-repo/backend/.venv/bin/uvicorn main:app --host 127.0.0.1 --port 8000
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

启动服务：

```bash
sudo systemctl daemon-reload
sudo systemctl enable video-downloader
sudo systemctl start video-downloader
sudo systemctl status video-downloader
```

## 六、配置 Nginx

### 1. 创建 Nginx 配置

```bash
sudo nano /etc/nginx/sites-available/video-downloader
```

写入以下内容（**替换 yourdomain.com**）：

```nginx
server {
    listen 80;
    server_name yourdomain.com;

    # 静态文件（前端）
    root /home/deployer/your-repo/frontend/dist;
    index index.html;

    # Gzip 压缩
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml application/xml+rss text/javascript;

    # API 请求代理到后端
    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # SSE 流式响应配置
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 300s;
    }

    # 前端路由支持（SPA + 管理后台）
    location /admin {
        try_files $uri $uri/ /admin.html;
    }

    location / {
        try_files $uri $uri/ /index.html;
    }

    # 静态资源缓存
    location ~* \.(jpg|jpeg|png|gif|ico|css|js|woff|woff2|ttf|svg)$ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
}
```

启用配置：

```bash
sudo ln -s /etc/nginx/sites-available/video-downloader /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

### 2. 配置 HTTPS（Let's Encrypt）

```bash
sudo certbot --nginx -d yourdomain.com
```

选择：
- 输入邮箱
- 同意服务条款
- 选择 `2`（强制 HTTPS 重定向）

证书自动续期：

```bash
sudo systemctl status certbot.timer
```

## 七、配置 Stripe Webhook（如果使用支付功能）

### 1. 在 Stripe Dashboard 配置

1. 访问 [Stripe Webhooks](https://dashboard.stripe.com/webhooks)
2. 点击 **Add endpoint**
3. 输入 URL：`https://yourdomain.com/api/payment/webhook`
4. 选择事件：`checkout.session.completed`
5. 复制 **Signing secret**（以 `whsec_` 开头）

### 2. 更新 `.env` 中的 Webhook Secret

```bash
nano /home/deployer/your-repo/.env
```

更新 `STRIPE_WEBHOOK_SECRET=whsec_your_production_secret`，然后重启服务：

```bash
sudo systemctl restart video-downloader
```

## 八、CORS 配置（生产环境必须）

生产环境需要限制 CORS。编辑 `backend/main.py`，将 `allow_origins` 改为你的域名：

```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=["https://yourdomain.com"],  # 改为你的域名
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

修改后重启：

```bash
sudo systemctl restart video-downloader
```

## 十二、安全建议

1. **定期更新系统**: `sudo apt update && sudo apt upgrade`
2. **配置防火墙**: `ufw enable` 只开放必要端口
3. **定期备份数据库**
4. **监控服务状态**: 使用阿里云监控或 Prometheus
5. **限制管理后台访问**: 通过 Nginx 限制 `/admin.html` 仅特定 IP 访问

## 常见问题

### Q1: Whisper 识别很慢怎么办？

在 `.env` 中改用 `tiny` 模型：
```env
WHISPER_MODEL=tiny
```

### Q2: 端口被占用？

检查并更换端口：
```bash
sudo lsof -i :8000
```

### Q3: Nginx 502 Bad Gateway？

检查后端服务是否运行：
```bash
sudo systemctl status video-downloader
```
