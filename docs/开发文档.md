## 1. 项目概述

**AI多平台视频下载分析平台** 是一个全栈 Web 应用，核心能力：

| 能力 | 说明 |
|------|------|
| 多平台视频解析下载 | 基于 yt-dlp，支持 1800+ 平台；抖音/B 站/快手有专用解析模块 |
| AI 视频总结 | DeepSeek 大模型生成 Markdown 摘要 |
| 思维导图 | 自动生成 markmap 可交互导图，支持 PNG/SVG 导出 |
| AI 问答 | 基于视频字幕的 RAG 式问答，带时间戳引用 |
| AI 内容创作 | 学习笔记 / 小红书文案 / 公众号大纲 / 记忆闪卡 |
| Whisper 语音识别 | 无字幕视频（如抖音）自动语音转文字 |
| 用户与会员 | JWT 登录、免费配额、Stripe VIP 支付 |

### 技术栈

| 层次 | 技术 |
|------|------|
| 前端 | Vue 3、Vite 7、Tailwind CSS 4、marked、markmap |
| 后端 | FastAPI、uvicorn、yt-dlp、httpx |
| AI | DeepSeek API（OpenAI SDK 兼容）、faster-whisper |
| 数据库 | SQLite（WAL 模式） |
| 支付 | Stripe Checkout + Webhook |

## 2. 系统架构

```
┌─────────────────────────────────────────────────────────────┐
│                    浏览器 (localhost:5173)                   │
│  Vue 3 SPA ── Vite 代理 /api ──► FastAPI (localhost:8000)   │
└─────────────────────────────────────────────────────────────┘
                              │
        ┌─────────────────────┼─────────────────────┐
        ▼                     ▼                     ▼
   视频解析层              AI 处理层              业务层
  downloader.py         summarizer.py         database.py
  douyin.py             asr.py                auth.py
                        api_summarize.py      api_payment.py
```

### 核心数据流

**视频解析 → AI 总结**

```
用户粘贴 URL
  → POST /api/parse（抖音/ B 站/快手走专用模块，其余走 yt-dlp）
  → 展示视频信息 + 格式列表
  → POST /api/summarize（SSE 流式）
       1. 提取平台字幕（B 站 API / yt-dlp）
       2. 无字幕 → Whisper 语音识别（asr.py）
       3. DeepSeek 流式生成摘要
       4. DeepSeek 生成思维导图 Markdown
       5. 持久化到 summaries 表
```

**AI 问答（可无字幕直接提问）**

```
POST /api/chat（SSE）
  → 有缓存字幕则直接用
  → 否则自动 Whisper 识别
  → DeepSeek 流式回答
```

## 4. 数据库设计

SQLite 文件：`backend/data/app.db`，启动时 `init_db()` 自动建表。

### users — 用户表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 用户 ID |
| email | TEXT UNIQUE | 邮箱 |
| password_hash | TEXT | bcrypt 哈希 |
| is_vip | INTEGER | 是否 VIP（0/1） |
| vip_expire_at | TEXT | VIP 过期时间 ISO |
| daily_summary_count | INTEGER | 当日已用总结次数 |
| last_summary_date | TEXT | 上次总结日期 |

免费用户每日 AI 总结上限：**3 次**（`FREE_DAILY_SUMMARY_LIMIT`）。VIP 无限。

### orders — 订单表

| 字段 | 说明 |
|------|------|
| order_no | 订单号，前缀 `XX` |
| stripe_session_id | Stripe Checkout Session ID |
| status | pending / paid |
| plan_type | monthly |

### summaries — AI 总结历史

| 字段 | 说明 |
|------|------|
| user_id + video_url | 联合唯一，同视频覆盖更新 |
| summary_text | Markdown 摘要全文 |
| mindmap_md | 思维导图 Markdown |
| subtitle_json | 字幕 JSON（含 segments） |

## 5. API 接口文档

> 交互式文档：http://localhost:8000/docs

### 5.1 视频服务（main.py）

| 方法 | 路径 | 鉴权 | 说明 |
|------|------|------|------|
| GET | `/api/health` | 否 | 健康检查 |
| POST | `/api/parse` | 否 | 解析视频元数据与格式列表 |
| POST | `/api/download` | 否 | 服务端下载后返回文件 |
| POST | `/api/direct-url` | 否 | 获取直链（前端暂未接入） |
| GET | `/api/proxy/thumbnail` | 否 | 缩略图防盗链代理 |
| GET | `/api/proxy/video` | 否 | 视频预览防盗链代理（抖音/快手等） |

**parse 请求体**

```json
{ "url": "https://v.douyin.com/xxx" }
```

**parse 响应 data 字段**

```json
{
  "title": "视频标题",
  "thumbnail": "https://...",
  "duration": 3600,
  "platform": "Douyin",
  "formats": [{ "format_id": "...", "label": "无水印 MP4 (1080p)" }]
}
```

### 5.2 用户认证（api_auth.py）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/auth/register` | 注册，返回 JWT |
| POST | `/api/auth/login` | 登录 |
| GET | `/api/auth/me` | 获取当前用户（Bearer Token） |

Token 请求头：`Authorization: Bearer <token>`

前端存储键名：`platform_token`、`platform_user`（localStorage）

### 5.3 AI 服务（api_summarize.py）

| 方法 | 路径 | 鉴权 | 说明 |
|------|------|------|------|
| GET | `/api/asr/status` | 否 | Whisper 配置状态 |
| POST | `/api/subtitles` | 是 | 获取字幕（含 Whisper 回退） |
| POST | `/api/summarize` | 可选 | AI 总结（SSE，需登录） |
| POST | `/api/chat` | 是 | AI 问答（SSE） |
| POST | `/api/generate-content` | 是 | AI 内容创作（SSE） |
| GET | `/api/content/scenarios` | 否 | 创作场景列表 |
| GET | `/api/summaries` | 是 | 总结历史列表 |
| GET | `/api/summaries/cached?url=` | 是 | 读取某视频缓存总结 |

#### SSE 事件类型（/api/summarize）

| event | 说明 |
|-------|------|
| `asr` | Whisper 语音识别进行中 |
| `subtitle` | 字幕数据 JSON |
| `summary` | 摘要 token（流式） |
| `mindmap` | `{ "markdown": "..." }` |
| `quota` | `{ "remaining": 2, "limit": 3 }` |
| `done` | 完成 |
| `error` | `{ "message": "...", "need_login": true }` |

#### SSE 事件类型（/api/chat）

| event | 说明 |
|-------|------|
| `asr` | Whisper 识别中 |
| `subtitle_ready` | 识别完成，返回字幕 JSON |
| `answer` | 回答 token（流式） |
| `done` / `error` | 完成 / 错误 |

#### AI 内容创作场景

| scenario | 说明 |
|----------|------|
| `study_notes` | 结构化学习笔记 |
| `xiaohongshu` | 小红书种草文案 |
| `wechat_article` | 公众号文章大纲 |
| `flashcards` | JSON 记忆闪卡 |

## 6. 核心模块说明

### 6.1 字幕提取（summarizer.py · SubtitleExtractor）

优先级策略：

```
抖音 URL     → 跳过平台字幕 → Whisper（douyin.py 下载）
快手 URL     → 跳过平台字幕 → Whisper（kuaishou.py 下载）
B 站 URL     → B 站 dm/view API（CC / AI 字幕）
其他平台     → yt-dlp subtitles > automatic_captions
无字幕       → asr.py Whisper 回退
```

字幕数据结构：

```python
{
    "has_subtitle": True,
    "language": "zh",
    "subtitle_type": "manual" | "auto" | "whisper",
    "segments": [{"start": 0.0, "end": 3.5, "text": "..."}],
    "full_text": "拼接全文"
}
```

### 6.2 Whisper 语音识别（asr.py）

- 引擎：[faster-whisper](https://github.com/SYSTRAN/faster-whisper)
- 抖音：通过 `DouyinParser.download()` 下载视频后识别
- 快手：通过 `KuaishouParser.download()` 下载视频后识别
- 其他：yt-dlp 下载 bestaudio，ffmpeg 转 mp3（`static-ffmpeg` 内置）
- 模型懒加载，首次调用会从 HuggingFace 下载（base 约 150MB）

### 6.3 AI 大模型（summarizer.py · VideoSummarizer）

- 接口：DeepSeek API（`https://api.deepseek.com`）
- 模型：`deepseek-chat`
- 输入截断：摘要/导图 15000 字符，问答 12000 字符
- Prompt 注入视频标题，字幕带 `[MM:SS]` 时间戳

### 6.4 国内平台专用解析

| 模块 | 文件 | 说明 |
|------|------|------|
| 抖音 | `douyin.py` | 短链/搜索页 modal_id/视频页；无 Cookie 无水印 |
| B 站 | `bilibili.py` | view + playurl API，绕过 yt-dlp 412 |
| 快手 | `kuaishou.py` | 移动端分享页解析，封面/预览/下载 |

### 6.5 配额逻辑（database.py）

```python
check_summary_permission(user_id)   # 检查，不扣减
increment_summary_count(user_id)      # 总结成功后扣减
```

无字幕 / Whisper 失败时不扣减次数。

## 7. 前端架构

### 页面状态（App.vue）

```
loading      → 解析中
videoData    → 解析结果，触发双栏布局
summaryKey   → 变更时 VideoSummary 重新挂载 / 重新总结
currentUser  → 登录态，传给 VideoSummary / PricingSection
```

### VideoSummary 五 Tab

| Tab | 功能 |
|-----|------|
| 总结摘要 | SSE 流式 Markdown 渲染 |
| 字幕文本 | 分段展示，支持 SRT/VTT/TXT 导出 |
| 思维导图 | markmap 渲染，PNG/SVG/全屏 |
| AI 创作 | 四场景内容二次生成 |
| AI 问答 | 多轮对话，自动 Whisper 补字幕 |

### Vite 代理

```js
// vite.config.js
proxy: { '/api': { target: 'http://localhost:8000' } }
```

开发时前端请求 `/api/*` 自动转发后端，避免 CORS 问题。

## 9. 本地开发

### 前置要求

- Python ≥ 3.10（推荐 3.12：`py -3.12`）
- Node.js ≥ 18
- ffmpeg（可选，项目内置 static-ffmpeg）

### 启动命令

```bash
# 方式 A：一键启动（Windows）
scripts\start-dev.bat

# 方式 B：手动
cd backend && python main.py          # → http://localhost:8000
cd frontend && npm run dev            # → http://localhost:5173
```

### 生产构建

```bash
cd frontend && npm run build   # 输出 frontend/dist/
# 后端可用 uvicorn 或 gunicorn 部署
```

## 10. 扩展开发指南

### 新增 AI 创作场景

1. 在 `summarizer.py` 的 `CONTENT_SCENARIOS` 添加 prompt 模板
2. 前端 `VideoSummary.vue` 的 `contentScenarios` 数组添加按钮
3. 无需改路由，复用 `POST /api/generate-content`

### 新增视频平台适配

1. 在 `douyin.py` 同级新建 `platform_xxx.py`
2. 在 `main.py` 的 `/api/parse` 路由添加 URL 判断分支
3. 返回与 `parse_video` 相同的数据结构

### 新增数据库表

1. 在 `database.py` 的 `init_db()` 添加 `CREATE TABLE IF NOT EXISTS`
2. 添加 CRUD 函数
3. 删除 `backend/data/app.db` 后重启即可重建（开发环境）

### 接入其他大模型

修改 `summarizer.py` 中 `VideoSummarizer.__init__`：

```python
self.client = OpenAI(
    api_key=os.getenv("OPENAI_API_KEY"),
    base_url="https://api.openai.com/v1",  # 或其他兼容端点
)
self.model = "gpt-4o"
```

## 11. 已知限制与后续规划

| 限制 | 说明 | 建议方向 |
|------|------|----------|
| 长视频截断 | 字幕超 15000 字符被截断 | Map-Reduce 分块总结 |
| CPU Whisper 慢 | 1 分钟视频约 30s～2min | 使用 cuda 或 tiny 模型 |
| 直链下载未接入 | `/api/direct-url` 已实现 | 前端优先直链，失败回退服务端 |
| 问答无多轮记忆 | 每次独立单轮 | 传入 chat history |
| marked XSS | AI 输出 v-html 渲染 | 引入 DOMPurify |
| CORS 全开放 | `allow_origins=["*"]` | 生产环境限制域名 |
